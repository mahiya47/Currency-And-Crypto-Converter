# Live Currency & Crypto Converter

A dynamic web application that provides real-time exchange rates for global fiat currencies and cryptocurrencies using a live data API.

## Features
* **Live Exchange Rates:** Fetches up-to-date conversion data via the Fawazahmed0 Currency API.
* **Smart Decimal Formatting:** Automatically adjusts decimal precision, displaying two decimals for fiat currencies and up to six for cryptocurrencies.
* **Market Sidebars:** Dynamically updates side panels with current rates for top fiat currencies (USD, EUR, GBP, JPY, AUD) and major cryptos (BTC, ETH, SOL, BNB, XRP).
* **Responsive UI:** Clean, interactive interface that updates immediately upon conversion.

## Tech Stack
* HTML5
* CSS3
* Vanilla JavaScript (ES6+ async/await, DOM manipulation)

## How to Run
1. Clone the repository or download the files.
2. Open `index.html` in your web browser.
3. Select your base and target currencies, enter an amount, and click "Convert".
